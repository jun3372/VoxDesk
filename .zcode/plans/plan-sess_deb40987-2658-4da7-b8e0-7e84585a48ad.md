# 离线语音转文字应用（VoxDesk）实施方案

## 目标

基于当前空白 Flutter 模板项目，构建桌面优先（**macOS + Windows + Linux**）的离线语音转写应用，UI 按 `docs/设计图` 7 张设计图还原（左侧栏 + 主内容区双栏布局，暖白底 + 品牌红 `#E5474D`）。

技术栈：`sherpa_onnx 1.13.x`（pub.dev 官方插件，各平台原生库随包分发）+ FireRedAsr2 AED（离线识别）+ Silero VAD + Pyannote segmentation + 3D-Speaker ERes2Net（说话人分离）+ 标点恢复模型（对应设计图"数字与标点规范化"）。

## 一、依赖与平台配置

**pubspec.yaml 新增依赖**：`sherpa_onnx`、`record`（麦克风 PCM 流）、`audio_decoder`（MP3/M4A/FLAC/OGG/WAV → PCM，原生解码）、`audioplayers`（结果回放条）、`file_picker`（选文件/选目录）、`path_provider`、`provider`（状态管理）；assets 仅声明应用图标。

- **macOS**：Debug/Release entitlements 加 `com.apple.security.device.audio-input`（麦克风）与用户选择文件只读权限；生成 Podfile。
- **Windows**：保持模板即可（WASAPI 原生支持）。
- **Linux**：模板即可，另在 `docs/MODELS.md` 注明运行需系统安装 PulseAudio/ALSA 开发库（`libpulse-dev`、`libasound2-dev`）。
- **Android/iOS**（保持兼容但不适配窄屏）：Android 加 `RECORD_AUDIO` 权限，iOS Info.plist 加 `NSMicrophoneUsageDescription`。

## 二、模型管理（脚本下载 + 应用内目录选择）

- `scripts/download_models.sh`（macOS/Linux）+ `scripts/download_models.ps1`（Windows）：从 GitHub Releases / HF 下载 4 组模型到 `models/` 目录：
  - `fire-red-asr2/`：sherpa-onnx-fire-red-asr2-zh_en-int8-2026-02-26（encoder/decoder int8 + tokens.txt）
  - `silero_vad.onnx`
  - `pyannote_segmentation-3.0.onnx` + `3dspeaker_speech_eres2net_base_sv_zh-cn_3dspeaker_16k.onnx`
  - `punct-ct-transformer/`（可选，标点恢复）
- `docs/MODELS.md`：下载与放置说明（含 Linux 系统依赖）。
- `services/model_manager.dart`：默认扫描 文档目录/voxdesk/models 与用户自选目录（递归匹配文件名，宽容 tarball 解包差异）；输出各模型就绪状态；加载/释放引擎。

## 三、核心服务层（lib/services/）

- `asr_engine.dart`：封装 `OfflineRecognizer`（`OfflineModelConfig.fireRedAsr` + `OfflineFireRedAsrModelConfig(encoder, decoder)`）；提供 `recognize(Float32List) → 文本`，在独立 Isolate 中运行并按句回调。
- `vad_engine.dart`：`VoiceActivityDetector` + `SileroVadModelConfig`（threshold 0.5 / minSilence 0.5s / maxSpeech 15s / window 512），输出带时间戳的语音段。
- `diarization_engine.dart`：`OfflineSpeakerDiarization`（pyannote segmentation + 3dspeaker embedding + `FastClusteringConfig`），用 `processWithCallback` 获取进度，返回 `(start, end, speaker)` 段列表。
- `audio_decode_service.dart`：`audio_decoder` 解码任意支持格式 → 重采样为 16kHz 单声道 Float32（Dart 线性插值）。
- `recorder_service.dart`：`record` 包 16kHz/单声道/PCM16 流 → Int16→Float32 转换 → 广播流。
- `history_service.dart`：历史记录持久化（文档目录/voxdesk/history/<id>/ 下 meta.json + transcript.json；实时会话另存 WAV，文件转写引用原路径）；支持列表/删除/导出 TXT。
- `punctuation_service.dart`：可选 `OfflinePunctuation`，模型缺失时优雅降级。

**文件转写管线**：解码 → VAD 分段 → 逐段 ASR（流式回显，进度=已处理时长/总时长，可暂停/取消）→ diarization（进度回调）→ 按 VAD 段与说话人段时间重叠匹配，合并同说话人相邻段为带时间戳+说话人标签的段落。
**实时转写管线**：麦克风流 → VAD → 语音段送离线识别（模拟流式，逐句出字，当前段显示"正在转写"高亮行）→ 结束时保存会话，后台对整段录音跑 diarization 并回填说话人标签。

## 四、UI 结构（lib/pages/ + widgets/，对照设计图状态机）

Shell（`home_page.dart`）：左侧栏 + 主内容区；主区顶部「语音转写」标题 + 副标题「高精度 · 本地处理 · 数据更安全」+ 右上「离线优先」盾牌徽章；下划线式 Tab「上传音频 / 实时转写」。

- **侧边栏**：Logo「FUNASR · OFFLINE / 离线语音工作台」；历史记录列表（文件类型彩色图标、名称、日期+时长、删除按钮，点击回看，选中高亮）；底部「加载模型」面板（状态胶囊 未加载/加载中/已就绪，"+" 展开后为：模型目录选择、各模型就绪清单、加载/释放按钮——替代设计稿中 FunASR 网络服务端口语义，保留视觉样式）；最底部环境信息（真实 OS/CPU，如 "macOS · ARM64 / Windows · x64 / Linux · x64" + "CPU"）。
- **上传音频 Tab**（4 状态）：空状态（虚线拖拽区 + 拖放支持）；已选文件（文件卡 + 更换/删除 + 标点规范化复选 + 「开始转写 →」）；转写中（进度百分比、已用/预计剩余、进度条、暂停/结束、结果流式输出）；转写完成（波形图 = 真实 RMS、字数统计、重新上传、带时间戳+说话人标签的结果列表、底部播放条：播放/进度/音量/倍速）。
- **实时转写 Tab**（3 状态）：就绪（麦克风大按钮、输入设备下拉默认"系统默认麦克风"——record 包不支持枚举设备、音频参数 16kHz/单声道/PCM 固定推荐值、开始按钮）；录音中（红点+计时器、动态波形、暂停/结束、逐句出字 + 高亮行、底部状态栏）；已结束（会话卡：日期/时长/设备、「已结束」胶囊、重新开始、完整结果、说话人标签回填中提示、汇总条「共 N 条结果」）。

**主题**（`core/theme.dart`）：背景 `#F8F0EC`、卡片白/`#FFFBFA`、主红 `#E5474D`（按钮渐变 `#E85A55→#D93A44`）、浅粉表面 `#FBEAE6`、虚线边 `#F0B9B0`、文字 `#2B2B33`/`#8A8A93`、成功绿 `#34A853`。设计稿笔误归一化：「高线优先」→「离线优先」，时间戳样式统一，Tab 统一下划线式。

## 五、验证

- `flutter analyze` 0 错误；`flutter test` 通过（替换模板计数器测试，新增：时长/时间戳格式化、说话人-VAD 段合并、历史存取的单元测试 + 主要页面冒烟测试）。
- `flutter build macos --debug` 编译通过（Windows/Linux 构建在本机无法验证，保持配置与依赖正确，文档注明构建命令）。
- 运行验证：有模型时实测文件转写与实时转写；无模型时应用可正常启动并引导下载/选择模型目录。
